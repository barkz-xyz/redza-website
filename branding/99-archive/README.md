# Archivo de experimentos rechazados

Esta carpeta conserva propuestas visuales que no están aprobadas para producción.

La subcarpeta `logo-v2-rejected-2026-09-17/` contiene los experimentos de logo V2 archivados por decisión del usuario. No copies esos archivos al sitio, a redes sociales ni a material comercial sin una aprobación explícita.

El sistema activo de Redza usa únicamente los logos oficiales en:

- `public/images/redza branding/white svgs/` para fondos oscuros;
- `public/images/redza branding/black svgs/` para fondos claros.
