# Redza logo V2 — sistema de lockups

> **Estado: archivado y rechazado.** Este material se conserva como referencia histórica y no está aprobado para uso en producción.

Esta carpeta contiene una propuesta V2 para hacer más flexible la presencia de Redza en web, redes, documentos y material comercial.

## Decisión de diseño

La V2 no redibuja el logo. Usa los SVG reales de Redza como piezas maestras:

- lettering oficial blanco o negro;
- truck oficial blanco o negro;
- rojo Redza como señal de ruta;
- tipografía de apoyo Manrope y DM Mono, igual que el sitio.

La mejora está en la composición, el espacio y la adaptación a distintos formatos. El lockup oficial original sigue siendo la fuente primaria hasta que esta propuesta sea aprobada.

## Archivos

- `redza-v2-horizontal-white.svg`: lockup horizontal para fondos `#0B0B0C` o `#151517`.
- `redza-v2-horizontal-black.svg`: lockup horizontal para fondos `#FFFFFF` o `#F3F3F1`.
- `redza-v2-compact-white.svg`: versión compacta para encabezados, firmas y perfiles.
- `redza-v2-compact-black.svg`: versión compacta para fondos claros.
- `redza-v2-usage-sheet.svg`: hoja de revisión visual y reglas de aplicación.
- `logo-v2-specification.md`: medidas, usos y criterios de aprobación.

## Regla importante

Los archivos apuntan a los SVG oficiales dentro de `public/images/redza branding/`. No se debe convertir el logo a texto, redibujar sus formas, estirarlo, rotarlo, cambiar sus colores ni pasarlo por un generador de imágenes.

Al mover estos SVG fuera del repositorio, conserva junto a ellos las carpetas de logos oficiales o incrusta las fuentes SVG con una herramienta vectorial antes de enviarlos a imprenta.
