# Tablero simple de resultados

Registrar una fila por conversación nueva. Puede hacerse en Excel, Google Sheets o una libreta mientras sea constante.

| Fecha | Empresa / contacto | Fuente | Origen | Destino | Carga | Fecha requerida | Estado | Siguiente paso |
|---|---|---|---|---|---|---|---|---|
| | | `CARD / WEB / IG / REF` | | | | | | |

## Métricas semanales

| Métrica | Qué cuenta | Meta inicial |
|---|---|---:|
| Tarjetas entregadas con conversación | Entregas a un contacto relevante, no tarjetas abandonadas | 10–15 |
| Escaneos o contactos `CARD` | Conversaciones que mencionan la tarjeta o usan su mensaje prellenado | 2–4 |
| Clics web a WhatsApp | Clics en el CTA principal | Crear línea base |
| Conversaciones calificadas | Incluyen origen, destino, carga y fecha | 3–5 |
| Cotizaciones enviadas | Propuestas concretas enviadas | 2–4 |
| Seguimientos realizados | Oportunidades retomadas dentro de 2–5 días | 100 % |
| Clientes nuevos | Servicios confirmados | Medir mensual |

## Etiquetas de origen

- `CARD`: tarjeta física.
- `WEB`: página web.
- `IG`: Instagram.
- `REF`: referido.
- `DIRECT`: contacto comercial iniciado por Redza.

## Decisiones al final del mes

- Si `CARD` genera conversaciones: imprimir una segunda tanda y ampliar lugares de entrega.
- Si la web recibe visitas pero pocos clics: reforzar el CTA y la prueba operacional.
- Si Instagram da visitas pero no conversaciones: reducir frecuencia y usarlo como portafolio, no como canal principal.
- Si las conversaciones no llegan con datos: repetir el marco `origen + destino + carga + fecha` en web, tarjeta y respuestas rápidas.
