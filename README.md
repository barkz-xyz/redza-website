# Redza — Brand & Website

Brand identity and a responsive website for a Chilean transport and logistics business. The project brings a custom visual system into a working Next.js interface.

## Highlights

- Custom SVG identity, route graphics, and service icons.
- Responsive desktop and mobile navigation.
- Service, coverage, client, and contact sections.
- Video-led hero and motion components.
- Direct quotation flow through WhatsApp.

## Stack

Next.js · React · TypeScript · Tailwind CSS · Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Build and run the application:

```bash
npm run build
npm start
```
